# Component Reference

## Core Customer Components
- **Navbar**: Sticky navigation, active section spy, mobile drawer, order tray trigger.
- **Hero**: Asymmetric editorial layout with word-by-word staggered reveal.
- **Menu**: Category-filtered grid with instant search and item modal.
- **CartDrawer**: Client-side persisted shopping tray with 5% GST calculation.
- **ReservationModal**: Form with date/phone/email validation and prototype confirmation.
- **VisitUs**: Contact form, opening hours, interactive map coordinates, concierge links.
