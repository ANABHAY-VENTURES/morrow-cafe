# Accessibility (A11y) Standards

## Guidelines Met
1. **Focus States**: Visible 2px terracotta outlines on `:focus-visible`.
2. **Reduced Motion**: Full support for `prefers-reduced-motion: reduce` disabling animations.
3. **Modal Dialogs**: `role="dialog"`, `aria-modal="true"`, and keyboard `Escape` dismiss.
4. **Touch Friendly**: Custom cursor completely disabled on coarse pointer devices.
