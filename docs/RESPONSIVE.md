# Responsive Breakpoints & Fluid Typography

## Screen Breakpoints
- **Small Mobile**: `360px` - `430px` (Single column, static card positioning)
- **Tablet**: `768px` - `1024px` (Adaptive 2-column menu grid, mobile drawer)
- **Desktop**: `1280px` - `1920px` (Asymmetric 12-column editorial grid, max-width: 1360px)
