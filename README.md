# MORROW CAFÉ (明日喫茶)

> A little pause from everything.
> Japanese minimalism meets European café warmth in Indiranagar, Bengaluru.

## Brand Essence
- **Palette**: Warm Ivory (`#F5F2EA`), Charcoal (`#242720`), Muted Sage (`#A3AA91`), Terracotta (`#BD785F`).
- **Typography**: Cormorant Garamond (Serif headlines), Plus Jakarta Sans (Body), Noto Serif JP (Calligraphy accents).
- **Interactive Experience**: Order Tray with GST calculation, Table Reservation system, Ambient vinyl player, Custom magnetic cursor.

## Quick Start

```bash
# 1. Install packages
npm install

# 2. Run dev server
npm run dev

# 3. Production build
npm run build
```
